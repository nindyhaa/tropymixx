# 🍹 TropiMix

TropiMix adalah web app tropical untuk membuat kombinasi minuman.

## 🚀 Upload ke GitHub Pages

**PENTING:** file `index.html` harus berada langsung di root repository.

Struktur yang benar:

```text
index.html
style.css
script.js
README.md
assets/
└── tropical-loop.wav
```

### Cara upload
1. Extract ZIP ini.
2. Masuk ke repository GitHub kamu.
3. Upload **semua file di dalam folder hasil extract**, bukan folder luarnya.
4. Pastikan `index.html`, `style.css`, dan `script.js` terlihat langsung di halaman utama repository.
5. Buka **Settings → Pages**.
6. Pilih **Deploy from a branch**.
7. Pilih branch `main` dan folder `/ (root)`.
8. Save.

Setelah beberapa saat, GitHub Pages akan menampilkan aplikasi TropiMix.

## 🎵 Musik
Tersedia musik tropical instrumental original di `assets/tropical-loop.wav`.
Klik tombol **Play music** di kanan atas untuk menyalakannya.
